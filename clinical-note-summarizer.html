How this works & how to make it production-ready: This demo runs a lightweight rule-based parser in the browser so it works offline with no API key. In production you would replace fakeSummarize() with a call to a HIPAA-eligible LLM (e.g. Azure OpenAI or AWS Bedrock under a signed BAA), send the note server-side, and never expose keys client-side. The SOAP schema, problem list, and code-suggestion UI stay exactly the same.
